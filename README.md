# โปรแกรมคำนวณประมาณการ ภ.ง.ด.51

เครื่องมือคำนวณประมาณการภาษีเงินได้นิติบุคคลครึ่งปี (ภ.ง.ด.51) แบบไฟล์เดียว ทำงานในเบราว์เซอร์ทั้งหมด

## ความสามารถ
- รองรับ SME (อัตราขั้นบันได) และบริษัททั่วไป (20%)
- นำเข้างบทดลอง (Trial Balance) จาก Excel ได้ 3 งวด และเปรียบเทียบพร้อม % ของรายได้ และคอลัมน์ปัดหลักพัน ('000)
- ปรับปรุงทางภาษี: ค่าใช้จ่ายที่ไม่ให้ถือเป็นรายจ่าย, รายได้ที่ได้รับการยกเว้น, ขาดทุนสะสมยกมา (5 รอบบัญชี)
- ประเมินความเสี่ยงประมาณการขาดเกิน 25% (มาตรา 67 ตรี)
- จัดสรรผู้รับผิดชอบ (Preparer / Reviewer / Approver) และพิมพ์สรุปแบบ ภ.ง.ด.51
- ติดตามงานทั้งสำนักงาน: แดชบอร์ดสถานะ, เตือนใกล้/เลยกำหนดยื่น, บันทึกการยื่นแบบและชำระเงินพร้อมไฟล์หลักฐาน

## ข้อมูลถูกเก็บที่ไหน

**โหมดออฟไลน์ (ไม่ได้เข้าสู่ระบบ)** — ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น
(`localStorage` สำหรับข้อมูลงาน และ `IndexedDB` สำหรับไฟล์แนบ) ไม่มีการส่งออกไปไหน

**โหมดระบบกลาง (เข้าสู่ระบบและได้รับอนุมัติแล้ว)** — ข้อมูลบริษัท **ถูกอัปโหลดขึ้น Google Firestore**
เพื่อใช้ร่วมกันหลายเครื่อง ซึ่งรวมถึงชื่อลูกค้า เลขประจำตัวผู้เสียภาษี ตัวเลขงบทดลองที่นำเข้า
และสถานะการสอบทาน — โปรดพิจารณาข้อผูกพันเรื่องการรักษาความลับของลูกค้าก่อนเปิดใช้
(ไฟล์แนบไม่ถูกอัปโหลด ยังอยู่ในเครื่องเสมอ)

> ⚠️ **ข้อจำกัดพื้นที่:** โหมดออฟไลน์ใช้ `localStorage` ซึ่งมีเพดานราว 5MB ต่อโดเมน
> งบทดลองที่นำเข้าจะถูกเก็บติดไปกับข้อมูลบริษัทด้วย จึงเก็บได้ประมาณ 25–55 บริษัท
> แล้วแต่ขนาดผังบัญชี เมื่อเต็มแอปจะขึ้นแถบเตือนสีแดงค้างไว้ — ให้กด
> “⭳ Export ข้อมูลทั้งหมด (Excel)” เก็บงานทันที แล้วลบบริษัทที่ไม่ได้ใช้ออก

## ⚠️ การตั้งค่าความปลอดภัย (จำเป็น ถ้าใช้ระบบกลาง)

แอปนี้เป็นหน้าเว็บล้วน โค้ดทั้งหมดรันในเบราว์เซอร์ของผู้ใช้ **การตรวจสิทธิ์ในหน้าเว็บ
(ซ่อนปุ่มตามบทบาท) เป็นเพียงความสะดวกในการใช้งาน ไม่ใช่ระบบความปลอดภัย** —
ใครก็เปิด Developer Console แล้วเรียก Firestore ได้โดยตรง

**ด่านเดียวที่กันได้จริงคือ Firestore Security Rules** ซึ่งอยู่ในไฟล์ [`firestore.rules`](firestore.rules)
ต้องนำไปติดตั้งก่อนใช้งานจริง:

```bash
firebase deploy --only firestore:rules
```

หรือวางเนื้อหาไฟล์ที่ Firebase Console → Firestore Database → Rules → Publish

สิ่งที่ rules บังคับไว้:
- สมัครเองได้ แต่ถูกตรึงเป็น `{approved: false, role: 'staff'}` เสมอ
- ห้ามผู้ใช้แก้ `approved` / `role` / `rejected` ของตัวเอง (มิฉะนั้นตั้งตัวเองเป็น partner ได้)
- เฉพาะ partner เท่านั้นที่อนุมัติผู้ใช้และเปลี่ยนบทบาทได้
- ข้อมูลบริษัทอ่าน/เขียนได้เฉพาะผู้ใช้ที่ได้รับอนุมัติแล้ว · ลบได้เฉพาะ manager ขึ้นไป

**แนะนำเพิ่ม:** ถ้าไม่ต้องการให้คนนอกสมัครบัญชีเองได้ ให้ปิด
Firebase Console → Authentication → Sign-in method → Email/Password → **Enable create (sign-up)**
แล้วให้ partner เป็นผู้สร้างบัญชีให้พนักงานใน Console แทน

## การเข้าสู่ระบบด้วย Google (SSO)

พนักงานกดปุ่ม **"เข้าสู่ระบบด้วย Google (SSO)"** แล้วเลือกบัญชี Google ของตน — ไม่ต้องตั้ง/จำรหัสผ่านของแอป
เข้าครั้งแรกระบบสร้างคำขอใช้งานให้อัตโนมัติ (ชื่อดึงจากบัญชี Google) และต้องรอ partner อนุมัติเหมือนการสมัครแบบเดิม

การตั้งค่า (partner ทำครั้งเดียว):

1. Firebase Console → Authentication → Sign-in method → **Google** → Enable
2. แอปต้องเปิดจากเว็บไซต์จริง (เช่น Firebase Hosting / GitHub Pages) — เปิดจากไฟล์ในเครื่อง (`file://`)
   หรือหน้าตัวอย่าง Artifact จะใช้ปุ่ม Google ไม่ได้ (ใช้อีเมล+รหัสผ่านได้ตามเดิม)
3. ถ้า host บนโดเมนอื่นนอกจาก `*.web.app` / `*.firebaseapp.com` / `localhost` ให้เพิ่มโดเมนนั้นที่
   Authentication → Settings → **Authorized domains**

## หมายเหตุ

เป็นเครื่องมือช่วยคำนวณเบื้องต้น โปรดตรวจสอบกับผู้สอบบัญชี/กรมสรรพากรก่อนยื่นจริง

## การทดสอบ

ชุดทดสอบ E2E (Playwright + Chromium) อยู่ในโฟลเดอร์ `tests/` ครอบคลุมสูตรภาษี, การนำเข้า/ส่งออก Excel + dedupe, และ UI smoke ทุกขั้นตอน

```
npm i -g playwright && npx playwright install chromium   # ครั้งแรกครั้งเดียว
node tests/run-all.mjs
```
